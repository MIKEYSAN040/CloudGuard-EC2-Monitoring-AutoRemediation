# CloudGuard – EC2 Monitoring & Auto-Remediation

An AWS monitoring and automated recovery project designed to detect **EC2 performance issues and automatically remediate incidents using CloudWatch and Lambda**.

## Architecture

**EC2 -> CloudWatch Agent -> CloudWatch Alarm -> AWS Lambda -> EC2 Remediation**

## AWS Services

* Amazon EC2
* Amazon CloudWatch
* AWS Lambda
* IAM

## What I Implemented

* Configured custom EC2 memory and CPU monitoring
* Installed and configured the CloudWatch Agent
* Created CloudWatch alarms for performance conditions
* Built a Lambda-based auto-remediation workflow
* Configured IAM permissions for automated EC2 actions
* Tested failure scenarios and validated recovery

##  Support Troubleshooting

Investigated and resolved realistic monitoring and automation incidents:


* Incident-01-CloudWatch Agent Stopped            
* Incident-02-Lambda IAM Denied
* Incident-03-EC2 Instance Availability Recovery                  
* Incident-04-Alarm Not Triggering          

## Support Workflow

**Detect -> Investigate -> Identify Root Cause -> Remediate -> Validate Recovery**

## Key Skills Demonstrated

**AWS Monitoring, EC2, CloudWatch, Lambda, IAM, Linux Troubleshooting, Log Analysis, Alert Investigation, Automation, Root-Cause Analysis, Incident Response**

## Project Outcome

Demonstrated hands-on ability to **monitor cloud infrastructure, investigate performance alerts, troubleshoot IAM and monitoring failures, and automate EC2 recovery using AWS services.**
